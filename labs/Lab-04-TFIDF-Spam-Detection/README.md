# TF-IDF Email & SMS Spam Detection
**Domain:** Artificial Intelligence and Cybersecurity  
**Notebook:** [`tfidf_spam_detection.ipynb`](./tfidf_spam_detection.ipynb)

## Overview
Implements Term Frequency–Inverse Document Frequency (**TF-IDF**) feature extraction and text vectorization to classify spam vs. legitimate messages in cybersecurity email/SMS datasets.

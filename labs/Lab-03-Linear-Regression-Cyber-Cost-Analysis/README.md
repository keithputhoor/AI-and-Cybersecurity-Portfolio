# Cyber Incident Cost Analysis with Linear Regression
**Domain:** Artificial Intelligence and Cybersecurity  
**Notebook:** [`linear_regression_cyber_cost.ipynb`](./linear_regression_cyber_cost.ipynb)

## Overview
Applies Supervised Linear Regression (`scikit-learn` / `numpy` / `matplotlib`) to model the relationship between the number of affected endpoints (`n_comp_affected`) and financial incident cost (`cost`), evaluating fit quality and plotting regression trendlines.

# Network Traffic Analysis & Attack Classification (NSL-KDD)
**Domain:** Artificial Intelligence and Cybersecurity  
**Notebook:** [`network_attack_classification.ipynb`](./network_attack_classification.ipynb)

## Overview
Performs multi-class and binary network intrusion detection on the **NSL-KDD** dataset, classifying normal traffic vs. Denial of Service (DoS), Probe, Remote-to-Local (R2L), and User-to-Root (U2R) attacks.
